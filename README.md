# OIT - Data Structures

This repository contains data structures I have implemented from scratch.

**List of data structures implemented:**

* One-Dimensional Array
* Multi-Dimensional Array
* Linked List
* Stack
* Queue
* Binary Search Tree
* AVL Tree
* Hash Table
* Graph

Included in this repository are labs that uses multiple data structures to make a console-based Minesweeper and use Dijkstra's Shortest Path algorithm.

Additionally, every data structure comes with their own UML diagrams and all code places emphasis on the importance of comment headers.
